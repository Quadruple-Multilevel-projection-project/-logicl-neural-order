# ניסוי ראשון — בדיקת נאמנות למקור

המטרה אינה לקבוע אם מודל "מבין". המטרה הראשונה היא לבדוק אם אפשר לבנות צינור שבו מקור קבוע נכנס, כמה תשובות מועמדות נשמרות בנפרד, ובדיקה מכנית מצביעה על השמטות ותוספות.

הבדיקה הנוכחית היא smoke test בלבד. היא אינה מחליפה בדיקה מול מודלים אמיתיים.

השלב הבא, אחרי שהצינור עובר, הוא להחליף את קבצי המועמדים בקריאות למודלים חיצוניים דרך API. המפתחות וההרשאות לספקי המודלים אינם נמצאים כרגע בחיבור GitHub ולכן לא נוכל להפעיל את החלק הזה אוטומטית בלי חיבור/Secrets מתאימים.
